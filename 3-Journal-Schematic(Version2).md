# **3. Updating the keyboard matrix and adding a few parts**

## **Updating the Matrix and Raspberry pi pico pin connections - 8/2/2026** (4 Hours)

This session was to remake the keyboard matrix and figure out the extra parts I planned on using. I used a new matrix that had 8 rows and 9 columns to reduce the pin usage down to 17 pins
while previously the matrix used 21 pins. I had a hard time figuring out how I would connect and figure out the footprint for the display I plan on using
(changing from an oled 0.91 inch display to an 8 pin ST7735 1.8inch TFT LCD display to better suit my end goal needs), but it ended up sparing a lot of pico pins. 
I also found the microSD card reader I wanted to use to store and load data into the pico.
