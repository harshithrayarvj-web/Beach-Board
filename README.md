# Beach-Board
First custom keyboard by me for the Hackclub KEEB Program. 

I want to take a shot at making something functional, real, and complete. I have some experience with fundamental logic gates in a digital setting (logisim and some others), but never built anything in real life, and building a keyboard would also help me understand how I/Os work in circuits and computers, but the project would also let me have experience with something like a pico board.
I do wish to take it a bit further by potentially using a rotary encoder as an extra more advanced input along with either an LED strip or an oled screen to react to inputs or show useful information/animated graphics.
